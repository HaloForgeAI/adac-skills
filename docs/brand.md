# ADAC Skills Brand

## Core Identity

- **Product name**: ADAC Skills
- **Method name**: Acceptance-Driven Agentic Coding
- **Skill name**: `adac`
- **Claude plugin command**: `/adac-skills:adac`
- **Generic invocation**: "Use ADAC for this task."
- **Tagline**: Acceptance first. Agents second.

## Positioning

ADAC Skills is a governance and delivery layer for AI-assisted engineering. It is not a model, editor, or test framework. It defines the contract that lets coding agents work inside an engineering process:

- context before generation;
- boundaries before implementation;
- acceptance before expansion;
- gates before release.

## Audience

- Engineering leaders who need repeatable AI coding governance.
- Senior engineers reviewing agent-generated changes.
- Teams turning one-off AI workflows into reusable skills.
- Tool builders packaging agent behavior for Claude, Codex, or internal platforms.

## Voice

ADAC should sound formal, practical, and calm.

Prefer:

- "evidence-backed delivery"
- "human gates"
- "acceptance matrix"
- "residual risk"
- "portable skill package"

Avoid:

- "AI writes code for you"
- "fully autonomous engineer"
- "tests prove correctness"
- "magic productivity"
- "prompt pack"

## Visual Direction

Recommended visual direction if the project gets a logo or docs site:

- calm engineering palette: dark ink, white, restrained violet or green accent;
- symbols: check gate, matrix, staged pipeline, handoff boundary;
- avoid cartoon robot imagery and hype-heavy gradients;
- use `ADAC` as the first-viewport signal; expand the full name below it.

## Upload Asset Checklist

For a polished public launch, prepare:

- `icon-512.png`: square icon for marketplaces and package cards;
- `social-preview.png`: 1280 x 640 GitHub/social preview;
- `hero.png` or `hero.svg`: site hero visual showing Context -> Spec -> Evals -> Gates;
- `demo-before-after.png`: simple visual of vague task to ADAC acceptance matrix;
- one short demo GIF/video for README or docs site;
- consistent display name: `ADAC Skills`;
- consistent package names: `adac-skills` and optional `@haloforgeai/adac-skills`.

The icon should be readable at small sizes. A good first logo direction is a four-cell matrix with a check gate, not a robot.

## Naming Rules

- Use `ADAC Skills` for the package/product.
- Use `ADAC` in conversation, commands, and examples.
- Use `Acceptance-Driven Agentic Coding` when defining the method formally.
- Use `adac-skills` for repositories, npm packages, and plugin identifiers.
- Use `adac` for the actual skill folder and direct invocation.
